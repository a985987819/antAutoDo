# antAutoDo

Android 本地支付宝任务助手，参考 Ant-Manor 与 Ant-Forest 的架构思路独立实现。

## 当前状态

已建立离线执行框架、预算门禁及任务规划；Android 17上的Auto.js Modify已完成监督下的导航、节点点击和部分森林浏览领奖。完整独立一键运行尚未验收，不是成品；手机端截图捕获已验证，稳定清晰画面、局部模板识别及自主好友循环仍未验收，本地OCR尚未验证。

本地验证（Node.js 22+，无依赖安装）：

```sh
npm test
npm run check
```

能力边界与手机连接步骤见 [真机验证说明](docs/device-bringup.md)。全部8类业务的独立运行状态与迁移批次见 [移动端能力审计](docs/mobile-capabilities.md)：当前完整独立闭环验收为0类。

## 目标范围

- 蚂蚁庄园：白名单打开/浏览任务；抽抽乐左右两个 Tab 各六次，优先原生自动连抽。
- 蚂蚁森林：本人成熟能量、已有免费奖励、白名单打开/浏览任务，以及用户已授权的有限好友收能量（最多50位、100次动作、10分钟）。
- 人工解锁、前台启动；暂停、急停、超时、兑换和抽奖限额。
- 无付费 API、云 OCR 或 YOLO 依赖。不提供规避检测、自动支付、自动解锁或验证码绕过；好友页不浇水、不购买、不用道具、不进行其他互动。

好友真机记录及未验收原型说明见 [好友收能量](docs/forest-friend-energy.md)。

具体页面规则未确认前保持禁用。平台可能限制自动化，需自行检查活动规则；不能保证账号不受限制。
