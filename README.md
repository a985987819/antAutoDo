# antAutoDo

Android 本地支付宝任务助手，参考 Ant-Manor 与 Ant-Forest 的架构思路独立实现。

## 当前状态

项目初始化阶段；尚无可在手机执行的任务，不是可直接使用的成品。Android 17、运行器、截图与离线 OCR 兼容性均待真机验证。手机暂未连接，先搭建离线框架。

## 目标范围

- 蚂蚁庄园：白名单打开/浏览任务；抽抽乐左右两个 Tab 各六次，优先原生自动连抽。
- 蚂蚁森林：本人成熟能量、已有免费奖励、白名单打开/浏览任务。
- 人工解锁、前台启动；暂停、急停、超时、兑换和抽奖限额。
- 无付费 API、云 OCR 或 YOLO 依赖。不提供规避检测、自动支付、好友收能量、自动解锁或验证码绕过。

具体页面规则未确认前保持禁用。平台可能限制自动化，需自行检查活动规则；不能保证账号不受限制。

## 里程碑

1. 工程规范和独立 Git 仓库。
2. 离线执行框架、安全测试和只读诊断脚本。
3. Android 17 真机能力探针和运行器适配。
4. 庄园任务与双 Tab 原生连抽。
5. 森林本人能量与免费任务。
6. 真机验收和使用说明。

每阶段验证后提交、推送并总结。离线测试不等于真机可用。
