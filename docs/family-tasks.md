# 家庭任务规则与真机记录

## 范围与入口

人工解锁后，从庄园底部“家庭”进入家庭页面，再打开“攒亲密度”。未知页面暂停。每天仅在人工启动时检查任务，尚未实现定时启动或保持亮屏。

## 用户确认规则

- 一起领外卖红包福利：确认目标页面打开后返回，重新核对状态，不下单。
- 每日捐蛋做好事：进入列表，选择第一项捐蛋任务，核对并仅捐1个鸡蛋。每天最多一次；不足、数量不明确、首项不可捐则停止，不自动改选。
- 帮喂家人小鸡：识别对应家庭小鸡弹窗后确认；未知消耗、购买或兑换提示暂停。
- 请家人吃一顿美食：手机本地时间早餐[06:00,11:00)、午餐[11:00,16:00)、晚餐[16:00,20:00)。只有当前餐次可完成且按钮明确允许执行时才进入确认；确认前复核时间与弹窗。未知费用暂停，不补做其他餐次。

已完成或“明天再来”跳过；不能只凭进度不足或时间符合执行。任务结束重新识别状态，不以点击返回值证明成功。以上规则尚未接入完整执行适配器。
