## 送你90g饲料奖励！

用户提到的“90s”实际页面为“90g”。页面说明为“恭喜完成淘金币浏览15s任务，点击立即领奖”。将其归为15秒浏览相关的后置奖励，而不是已确认独立打开任务。记录关联时长15秒，但按钮待完成时暂停核实前置条件；可领取时直接领取，已领取跳过。不能凭描述再次进入并机械等待15秒。

## 状态与安全规则

1. 精确白名单匹配任务标题，不对所有“去完成”批量点击。
2. 适配器必须先验证任务行、描述与对应按钮关联；部分节点将标题/描述/状态拼成一个文本，不能直接用全文作为标题，亦不能把说明中的“领取”当按钮状态。
3. 已领取（包括“已领取更多视频”）映射claimed，直接跳过，不点更多视频。明确可领取才映射claimable，明确待执行才映射pending；未知状态暂停。
4. 屏外、零面积、部分裁切或被遮挡的任务不可点击，先定位完整可见行并重新识别。
5. 返回后必须确认饲料列表，重新定位同一任务后领取一次，再核对已领取和奖励结果。饲料满仓或不明弹窗时暂停，不盲目重领。
6. 打开任务可能切换淘宝等应用：后续动作适配需逐项配置允许的目标包名和页面信号，只允许等待及安全返回，不能为此放开全局任意包点击。未知包名暂停。
7. 不因为奖励文字看似免费而自动登录、同意授权、支付或关闭系统保护。所有动作受超时、次数和人工急停限制。
