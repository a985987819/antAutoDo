# 森林好友收能量：阶段记录

## 范围与规则

用户于2026-11-17明确授权从“找能量”进入好友森林，收取可收能量，再上滑切换下一位。最多50位、100次动作、10分钟，任一先到停止；不浇水、不购买、不使用道具、不复活过期能量、不执行留言等其他互动。不添加检测规避行为。保持手机人工解锁、支付宝前台。

每页先验证好友页面与唯一“一键收”，点击后确认按钮消失，再上滑并确认换页。无匹配、未知页面、锁屏、后台、重复标题或无法确认换页停止，不把识别失败当成没有能量。标题仅用于保守的重复停止，不作为唯一好友身份凭据。同名可能提前停止。

## 已完成的真机验证

- 人工监督实时截图下，“找能量”可进入好友森林；上滑可切换下一位，底部提示为“上划找更多能量”。
- 单个明确标注可收取的球已获得2g，收取文本与本人余额均变化。
- 右侧“一键收”在多个好友页可一次收取当前可收球；收取后按钮消失。未出现道具确认，本轮未点击浇水、道具、复活或倒计时球。
- 截图核对的本人余额从23636g增加至23741g，累计增加105g（含最初单球2g）。这属于电脑监督下逐步操作，不代表手机自主循环成功，也未遍历到终点。
- 手机端requestScreenCapture返回true，captureScreen可获得1220×2656画面；仅证明可捕获，不证明每一帧清晰可用。

## 未验收原型

`forest-energy-prototype.js`保存本轮手机端同步循环实验代码，默认仅适配本次1220×2656布局。不是正式入口，不自动启动或调度。需手机端自行匹配局部模板，不依赖电脑逐张判断；模板为本机调试素材，不随仓库提供。没有模板时无法运行。代码仍有硬编码布局和有限的页面/弹窗识别，不能直接用于无人监督运行。

本次自主循环测试均在点击前停止，0次收取：先因模板未匹配停止；诊断发现授权退出时捕获到模糊过渡画面；添加1.8秒等待后，又因无法确认已恢复好友页停止。过渡画面是已观察到的失败因素，不断言它是唯一原因。没有用降低阈值、屏幕盲点或忽略错误绕过。

后续先修复截图授权后前台恢复与稳定画面判断，再验证单页匹配、按钮消失后置条件、换页与终点识别、停止机制和小范围循环。按钮消失本身仍不是精确到账数量证据，正式版本需进一步核对收取结果。未完成离线完整状态机和手机适配验收。
