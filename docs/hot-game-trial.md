# 试玩庄园火爆小游戏：50秒退出策略

## 现行规则

用户已将此前等待多轮圆环结束的策略改为：对于“最高240g”任务，从确认进入游戏开始等待50秒，关闭小游戏，返回饲料任务列表查看并领取实际可领奖励。不再为凑满240g持续等待；50秒不代表必得某个数量。

`src/tasks/manor/cyclic-feed.js`仅为纯决策函数，不包含手机执行、定时器或图像分析。调用方应以单调时间计算从已验证入口开始的总时长，不按每轮重置；50秒前返回剩余等待时间，到时输出关闭并检查奖励计划。未知页面或遮挡仍暂停，不能因到时而盲点；需验证宿主关闭目标，不能确认游戏内账号、服务器提示。

返回后重新识别任务列表，仅在领奖行已验证且可见时计划领取一次，随后核对实际结果。遇已识别的容量不足警告，关闭弹窗并停止本次领奖，交由用户决定；不确认部分领取，不自动喂食或兑换腾空间。未知弹窗暂停。

## 真机观察（2026-11-17）

- 任务说明为打开即得30g，最多240g，初始进度0/240。
- 实际可见任务仍可能在控件树中显示零坐标。人工截图确认后，在唯一两子节点容器定位“去完成”，节点点击成功进入游戏；不推广为盲点屏外节点。
- 本次游戏为三国冰河时代，有服务器提示，未确认。左侧奖励浮层黄色圆环变化，树中无可读秒数。自动圆环分析未实现，现行策略无需等待圆环结束。
- 点击已核对的宿主“关闭”后，出现添加桌面挽留弹窗；用户指定点左下“退出游戏”，未点击添加桌面。
- 返回列表出现“领取210克饲料”；点击一次后提示饲料袋快满，仅余16g容量。
- 按用户要求关闭满仓弹窗。已验证提示消失且210g仍待领取，未确认部分领取，没有验证到账。
- 本次在游戏中停留已超过50秒，210g不是50秒策略的收益证据。50秒自动退出完整流程尚未实测。
