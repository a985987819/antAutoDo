# 抽抽乐：按时长相关的游戏任务

## 分类与范围

这是蚂蚁庄园「抽抽乐」中的独立任务类型：**按时长相关的游戏任务**。它不是普通打开任务、杂货铺滑动浏览任务，也不是要求通关、完成订单、招募英雄或消费的游戏进度任务。

已通过人工操作、ADB只读观察验证的案例：右侧Tab的「【限时】去玩智商乐消消」，描述为「玩30s休闲小游戏，得1次新机会」。任务名称、Tab活动文案可能变化，不能仅凭“游戏”或“限时”自动归类。其他游戏须逐项确认后加入白名单。当前只记录规则，尚未实现自动执行或Auto.js游戏页面读取。

## 执行规则

1. **任务页预检**：确认抽抽乐、已验证的目标Tab、白名单任务标题及按时长描述。读取可见剩余机会作为基线。唯一定位该任务对应按钮；有歧义则暂停。
2. **按按钮分流**：
   - `去完成`：进入对应游戏。
   - `领取`：不重复进入游戏，直接走领奖步骤。
   - `已完成`：跳过，不重复执行。
   - 其他状态：暂停检查。
3. **进入游戏**：重新确认目标游戏和右侧奖励区域。按时长描述是任务门槛，不是固定sleep后成功的依据。
4. **等待奖励就绪**：本例初始区域显示「玩30秒」「可得1次机会」，结束后显示「抽奖机会」「已发放」。必须在同一已确认奖励区域识别成对文字；游戏其他位置出现“完成”等字样不算。尚未验证逐秒倒计时是否可读，不能声称已支持。
5. **安全返回**：游戏内「已发放」仅表示可以返回任务页领取，**不表示抽奖机会已经到账**。执行一次返回并检查抽抽乐任务页；停在退出确认或未知页面时暂停，禁止连续盲按返回。
6. **重新定位领取**：返回后重新采集页面，找到同一任务的`领取`按钮；不沿用进入前的节点、索引或坐标。若已完成则先核对到账；若仍为去完成则报告未完成，不无限重玩。
7. **领取并核对**：只点击对应任务的一次领取，重新读取机会数和任务按钮。正常情况应为机会数增加该任务声明奖励（本例+1）且任务已完成。领取后若发生超时或状态不确定，暂停并重新观察，不能盲目重试领取或抽奖。
8. **结束**：此任务只获取机会，不自动抽奖。抽奖由独立的抽抽乐调度与次数预算决定；额外获得的机会不能被每Tab六次连抽默认消耗。

## 时限和异常处理

- 后续实现按任务声明时长设置有限等待上限，启动加载和完成检测各有额外有限余量；超时暂停，不把等待结束当作完成。具体参数待执行器实现时配置并测试。
- 无障碍控件文字优先；只有确实不可读时才评估本地局部OCR，不引入YOLO或付费服务。
- 遇支付、授权、登录、验证码、要求实际游戏操作、未知弹窗、前台切换或锁屏即暂停。不自动同意权限，不绕过安全保护。
- 任务和按钮可能是大容器下的同级节点，不能假定每项具有独立行容器。后续提取器必须以任务标题、描述、限定兄弟序列和唯一可见按钮共同划定任务边界；不得在大容器里寻找第一个“领取”，也不得只按最近Y坐标配对。
- 屏外和零面积控件不可点击；需要滚动时先重新确认任务页，滚动后重新识别。

## 已观察到的闭环

`去完成 → 游戏右侧玩30秒/可得1次机会 → 抽奖机会/已发放 → 人工返回 → 任务按钮领取、机会仍0 → 人工领取 → 机会1、任务已完成`。

任务已完成后的标题/按钮节点可能移到屏外。因此本次可见的0→1是主要到账证据，屏外已完成节点只作为辅助观察，不用于自动点击。

## 后续必须补充的测试

白名单与任务分类、进入前已完成/可领取分流、倒计时或完成区域误匹配、等待超时、退出确认、返回页面不匹配、任务重排、按钮歧义、领取后机会未增加、领取后任务屏外、重复运行、前台中断。人工闭环不等于自动化验收；自动执行需另行实现和真机验证。
